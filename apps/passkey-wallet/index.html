Passkey post-quantique (Ledger Stax)

Une passkey WebAuthn ML-DSA-44 (COSE -48) créée sur la Stax par l'app Security Key modifiée, enregistrée sur le ledger par PasskeyListSet (sa clé publique de 1 312 octets) et vérifiée par le nœud à chaque signature (amendement PasskeyMLDSA). Chrome, Stax branchée en USB, app Security Key ouverte.

Nœud de test uniquement, graine en clair : la graine de la clé maître du compte est gardée en clair dans ce navigateur jusqu'au verrouillage. La section refuse de créer un compte si le nœud n'est pas local ou listé dans VITE_TEST_NODE_HOSTS.

    Migrer vers la racine ML-DSA-44

    Trois transactions, dans cet ordre : la clé ML-DSA-44 de la Stax devient la clé régulière, elle prouve qu'elle signe pour le compte, puis la clé maître classique est désactivée. Après l'étape 3, seule la clé ML-DSA-44 signe : la perdre bloque le compte pour toujours. Avant l'étape 3, réinstallez l'app XRP sur la Stax et relisez la clé : elle doit être identique (même seed, même clé).
