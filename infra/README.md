# infra

Everything needed to run the daemon and the demo locally.

| File             | Purpose                                                                                                                                                                                                                                                                                                                                                                                                         | Status  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `standalone.cfg` | Standalone `xrpld` configuration whose `[amendments]` enable every amendment this build supports and does not veto (121), among them `Passkey`, `Quantum`, `PasskeyMLDSA`, `SigningSessions`, `BatchV1_1`, `PermissionDelegationV1_1`, `fixPasskeyChallenge` and `fixP256StrictDer`, in the genesis ledger of `--start`, with a public non-admin WebSocket for the app and a separate admin port for the closer | task N9 |
| `closer.ts`      | The single process that calls `ledger_accept` every 3 seconds (session expiry is measured on ledger close time)                                                                                                                                                                                                                                                                                                 | task N9 |
| `compose.yaml`   | The node, the closer and the passkey test wallet as one stack; the wallet service builds `apps/passkey-wallet`, which is not on `develop` yet                                                                                                                                                                                                                                                                   | task N9 |
| `Dockerfile`     | The node, so the demo can run without a long C++ build                                                                                                                                                                                                                                                                                                                                                          | stretch |

The genesis seed comes from an environment variable and is never committed. Start from the example configuration upstream (`rippled/cfg/`).
