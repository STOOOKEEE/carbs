# Brand

The carbs logo: the "c" of the wordmark, set in Clash Display Semibold (the font of the header wordmark, `apps/web/public/fonts`), navy `#000637` on cream `#f5f4e7` (the `--brand-navy` and `--brand-cream` tokens of `apps/web/assets/tokens.css`), on a square.

| File                                      | Use                                     |
| ----------------------------------------- | --------------------------------------- |
| `carbs-logo.svg`                          | vector, any size; also the site favicon |
| `carbs-logo-1024.png`, `-512`, `-256`     | submission forms, slides, social cards  |
| `carbs-logo-180.png`, `carbs-logo-32.png` | touch icon and small icon sizes         |

The glyph is the font's own outline (converted with fontTools), so the SVG needs no font at render time.
